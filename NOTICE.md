# Authorship and release provenance

**Project, concepts and original Organism 8/9 lineage:** Nicolae Pascal.

The supplied `GENESIS_11_bundle.zip` is the input to this publication package. It describes a browser adaptation of `Architect-Flow78/Organism-9-ciastica2/organism_unified.py`, produced with ChatGPT assistance. Its source attribution and CC BY 4.0 notice are retained.

The engine (`genesis_engine.js`) and original tests (`test_genesis.js`) are unchanged in this package. The Russian single-file demo is retained as `GENESIS_11_RU.html`.

Publication additions, 7 October 2026: English interface text and single-file demo, English/Russian README, headless CLI example, publication text, evidence index and contribution notes. Model dynamics were not changed to obtain the example results. Browser drawings are artistic representations, not reconstructed physical soliton geometry.

Published source: https://github.com/Architect-Flow78/genesis-world-memory. Website activation and LinkedIn posting are separate actions. Publication media can be regenerated from the real browser interface with scripts/render-publication.cjs; exact descendants depend on the time of intervention.
