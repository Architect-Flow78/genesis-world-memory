# Публикация GENESIS

Репозиторий: https://github.com/Architect-Flow78/genesis-world-memory

Исходники размещаются в корне, а не только в архиве. Английская демонстрация — index.html, русская — GENESIS_11_RU.html. Код модели: genesis_engine.js. Тесты: node test_genesis.js. Пример: node examples/compare-memory.cjs.

## Метки GitHub (Topics)

artificial-life, environmental-memory, agent-based-modeling, generative-art, simulation, javascript

В блоке About справа на главной странице репозитория нажмите шестерёнку и вставьте эти метки. Метки в README — только текст, не настройка Topics.

## Включить демонстрацию в браузере

Settings → Pages → Deploy from a branch → main → / (root) → Save.
Ожидаемый адрес после успешного развёртывания: https://architect-flow78.github.io/genesis-world-memory/
До проверки развёртывания этот адрес не считается опубликованным. После проверки добавьте его в поле Website в About.
