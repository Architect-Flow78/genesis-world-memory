## English — text for publication

**The agent disappears. Its legacy stays in the world.**

I built GENESIS, a small JavaScript artificial-life sandbox exploring that idea.

Retire an agent and it leaves a fading “scar”: its location, internal parameter K, experience and lineage. A later birth nearby can inherit part of that record. The next agent is not spawned automatically when the previous one dies.

The demo includes a direct test: clone the same world, erase existing scars in one copy, then run both with the same external field noise. Compare births, inheritance and the resulting states. New scars remain possible in both branches.

Open a single HTML file to try it. Or use the engine separately in Node.js to run your own experiments. No external packages or API keys are required; tests and snapshot export are included.

This continues my TPM / Organism 8–9 project. It is an explicit computational model of environmental memory, not a claim of biological life or consciousness.

For simulation developers and artificial-life researchers: which scar mechanism would you change first—its lifetime, influence on births or inherited parameters?

Code and demo: https://github.com/Architect-Flow78/genesis-world-memory

## Русский — перевод

**Агент исчезает. Его наследие остаётся в мире.**

Я создал GENESIS — небольшую JavaScript-модель искусственной жизни, исследующую эту идею.

После исчезновения агент оставляет затухающий «шрам»: место, внутренний параметр K, опыт и происхождение. Более позднее рождение поблизости может унаследовать часть этой записи. Новый агент не создаётся автоматически в момент смерти предыдущего.

В демонстрации есть прямая проверка: сделать две копии одного мира, стереть существующие шрамы в одной и продолжить обе при одинаковом внешнем шуме поля. Сравнить рождения, наследование и получившиеся состояния. Новые шрамы могут появляться в обеих копиях.

Чтобы попробовать, достаточно открыть один HTML-файл. Или использовать движок отдельно в Node.js для собственных экспериментов. Внешние пакеты и ключи API не нужны; в комплекте тесты и экспорт состояния мира.

Это продолжение моего проекта TPM / Organism 8–9. Перед вами явная вычислительная модель памяти среды, а не заявление о биологической жизни или сознании.

Разработчики симуляций и исследователи искусственной жизни: что вы изменили бы первым — длительность следа, его влияние на рождения или наследуемые параметры?

Код и демонстрация: https://github.com/Architect-Flow78/genesis-world-memory
