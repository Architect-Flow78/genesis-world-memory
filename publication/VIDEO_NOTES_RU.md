# Записи для публикации

assets/preview-en.mp4 и assets/preview-ru.mp4 — записи запуска браузерной модели.

Ролики, снимки и браузерные проверки в репозитории можно воспроизвести через scripts/render-publication.cjs. Поколение и номер потомка зависят от момента вмешательства. Конкретные наблюдения записываются в evidence/publication_render.json. Таблица README относится к отдельному фиксированному запуску Node.js.

Leave a scar — «Оставить след». The legacy continues — «Наследие продолжается». Compare two futures — «Сравнить два будущих».

Это выполняемая цифровая модель с заданными правилами. Не съёмка физических солитонов и не доказательство сознания.
