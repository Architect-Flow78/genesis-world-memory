What is happening here

This is a running digital ecology, not a recorded animation. Agents are created by birth rules applied to excited regions of a ring field. The initial view shows a computed world after 1,600 steps.

Continuing Organism 8/9

Based on Organism 8 + Organism 9: a discrete sine–Gordon field, a birth threshold, K, fast/slow memory, tension, fear, experience, generations and death-to-field feedback. The divisor-count radial landscape is retained. K is not forcibly pulled toward the golden ratio.

What this version adds

A persistent scar stores an agent's K, experience and lineage. It lowers the local birth threshold. A later agent nearby may inherit part of K and 60% of experience. Birth still requires an excited field and free space. A scar does not guarantee an immediate descendant.

Death no longer creates an unconditional immediate replacement. This version adds seeded randomness, light field damping, a birth probability and environmental memory. Constants are parameters of this experimental model, not universal constants of life.

How to test memory

Compare two futures clones the current state and erases only existing scars in one copy. Both then run for 1,800 steps with the same external field noise. New scars remain enabled in both. Births, inheritance, agent parameters and the field are compared. Results depend on the starting snapshot; no outcome is forced.

How to read the scene

Glowing organisms are artistic agent representations, not verified soliton shapes. Colour denotes family, the shell responds to coherence and K, and lines connect ancestors and descendants. Gold traces are surviving scars. Rendering a ring field this way does not make it a physical 3D simulation.

Life, character and reincarnation are names for programmed mechanisms. This model does not establish consciousness, biological life or stable topological solitons. The effect of retaining versus erasing existing memory is reproducible.

Controls: click an agent to select it; click empty space to excite the field; space to pause. Images and JSON snapshots are saved locally. No API calls, accounts or paid libraries; nothing is written to GitHub.
